# Environmental Monitor Frontend

### Work In Progress!

A React + Vite + TypeScript frontend currently in development in order to expose the [Environmental Monitor Backend](https://github.com/alex-jns/environmental-monitor-backend). Presents inside and outside weather conditions to the user in the form of a website.

# Planned Features

- Shows inside and outside weather conditions
- Allows users to generate and display changes in weather over a time period
- Interactive dashboard that gives users a at-glance update on current weather

# Usage

1. Clone the repo

```
git clone https://github.com/alex-jns/environmental-monitor-frontend.git
cd environmental-monitor-frontend
```

2. Install dependencies

```
npm install
```

3. Run the development server

```
npm run dev
```

4. Open the site on your browser

```
http://localhost:5173/
```
